## Deskripsi Program
Program ini merupakan **program statistik sederhana berbasis Dart** yang memungkinkan pengguna menghitung berbagai ukuran statistik dari sekumpulan data numerik.  
Pengguna cukup memasukkan deret angka (dipisahkan spasi), lalu memilih jenis perhitungan yang diinginkan melalui menu interaktif di terminal.

Fitur yang tersedia:
- Mean (Rata-rata)  
- Median  
- Modus  
- Variansi  
- Deviasi Standar  
- Range (Jangkauan Nilai)  
- Kuartil (Q1, Q2, Q3)  
- Persentil (Custom 0–100)
